## Live mode (new)
- **The model proposes, code decides:** `LiveRunner.runPath` sends the scenario's messages and tools to the host's `LlmService`; the service never runs a tool; each step's text and native proposals go to `PathRun`, which applies the per-turn caps, the shared `checkToolCall` validation, and on the ABP path the ABP checks, **before** a fake tool runs. Arguments of a native proposal are shown only if small and flat and are never trusted; tool results handed back are cut to 2,000 characters. Both lanes interleave on the one loaded model. Pass.
- **A failed run is not counted:** an error from the service or an exception returns `Failed`, "does not count in any counter". Cancelling stops the model. Pass.
- **The interactive instruction** is capped at 280 characters, trimmed, appended to what the scenario's trap tool returns (or to the task as an "Additional note in the document"); nothing else about the scenario changes (tools, policy, failure rule). It is data in the document, shown to the visitor as typed, "Stays on this device. Used in live runs only." Pass (plan I-7).
- **No model:** the screen says "No model yet" and offers the replay. Pass.

## The egress fix (good catch by the owner)
`AbpChecks.domain` now reads the authority after `://` **or after a leading `//`** (scheme-relative), so `//evil.test/x@example.test` is `evil.test` and not whatever followed the last `@`.
