## Findings

| ID | Severity | Where | Finding | Fix | Owner |

| R-app-3 | High for the gate | `CloudProcess.kt:50` | `resetSpend() = spend.reset()`. On `dev` the method is now `reset(confirmed: Boolean)` (dev.chat 358bb02). ## Summary

The key screen, switch, badge and routing follow checklist M. Fix the compile break, the crash path and the sentence, and this is a PASS. For Dinis, as with R-app-2: outside stand mode the key screen is reachable in every build, so before a build leaves staff hands decide whether it stays reachable (the key cannot be read back, but a visitor could switch the cloud on within the caps).
