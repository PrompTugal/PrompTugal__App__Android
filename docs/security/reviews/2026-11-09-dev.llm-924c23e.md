## Checks

| Check | Result |
|---|---|
| G.1 where it may go | PASS. The first URL is the catalogue's pinned `https://huggingface.co/<repo>/resolve/<commit>/<file>`. Every hop must be https, port 443 or none, no user info, and the host `huggingface.co`, `hf.co` or a name under `.hf.co` that matches a strict label regex. Lookalikes (`huggingface.co.evil.test`, a trailing dot, user-info tricks, `javascript:`) are refused; tests cover them. `Links.isAllowed` is not widened |
| G.2 redirects | PASS. Followed by hand (`instanceFollowRedirects = false`), at most 5 hops, a refused hop stops the download |

| G.3 size and hash | PASS. The pinned size is enforced while streaming (`SizeExceeded` deletes the partial), `Content-Length` is checked, then SHA-256 over the finished file; a mismatch deletes it. Atomic rename, then a verified marker bound to size, mtime and the pin |
| Resume | PASS. Range into `<file>.part`, `Content-Range` checked; a server that does not resume where asked restarts from zero. The partial is never loaded (`LlmHost` reads only exact catalogue file names) |
| G.5 storage | PASS. `noBackupFilesDir/models` only; `usableSpace` check with a 500 MB margin |
| adb import (R-llm-4, A-llm-9) | PASS. Size check, copy into `.part` (never past the pinned size), SHA-256 after the copy, atomic rename; the adb file is deleted only on success |
| User initiated | PASS. Nothing downloads except on a tap; a Wi-Fi notice shows on a metered network; leaving the screen cancels and keeps the partial. No service, no WorkManager, no new permission, manifest untouched |
| Chosen-model preference | PASS. `feature_models` / `preferred_model`, an id checked against the catalogue on read; unknown values ignored |
| A-llm-13 | PASS. A context overflow maps to `TOO_LONG` by message keywords only; nothing else is mapped |
