## The adb folder, as asked
Reading the bench's model files from `/sdcard/Android/data/ai.riskmandate.app/files/models/` is **acceptable for a bench on Android 11 and later** (API 30+): scoped storage keeps other apps out of `Android/data/<package>`, so only the app, adb and root can write there, and the SHA-256 is checked before each load. On **Android 10 and older** (the app's minSdk is 26) another app with storage access could replace the file between verification and load. The target tablet runs Android 15. See R-llm-4.
