Features

What exists today

The app is small on purpose. Everything on this page is checked against the source when the site is built.

In the app now

  • One button, “Open riskmandate.ai”. It opens the site in a Chrome Custom Tab, or in the browser the system picks if none supports Custom Tabs. If there is no browser, the app says so.
  • An address check. The app opens only https addresses on riskmandate.ai or www.riskmandate.ai, on port 443 with no embedded user name. Anything else is refused with a message. (A security review found this check could be fooled; it was fixed. See the article.)
  • A Device section. It says whether an organisation manages the device (fully managed, work profile, or not detected) and shows an optional device label.
  • Managed configuration. An organisation’s device management can set the page the app opens (start_url, checked by the same address rule) and the device label (device_label). This is groundwork for managed devices; no device has been enrolled yet.
  • A Diagnostics screen for testers: app and Android version, device model, management state, the managed configuration as received, and which app installed this one, with a Copy button. It holds no personal data and no device identifiers.
  • An offline hint, using the network-state permission only to say the device seems to be offline.
  • An open-source licences screen with the full Apache 2.0 text.
  • Light and dark themes, tablet layouts, {{locales}}. The home screen shows two panes side by side in landscape when the screen is wide enough, as on 7 and 10 inch tablets.

The build number is shown at the bottom of the home screen; quote it when you report a problem.
