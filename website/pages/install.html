For testers

Install RiskMandate on Android

The app is not on Google Play. Testers get it from Firebase App Distribution, through Google’s App Tester app. After the first install, each new build is one tap.

Testers are invited by the operator, Dinis Cruz, who adds your Google account to the tester group. Ask him; no address is published on this site. Use the same Google account everywhere below.

Before you start

  • An Android phone or tablet, Android {{min_android}} or later.
  • A Google account that has been invited. Firebase emails the invitation; check spam. It expires after 30 days; ask for a new one if it has.

First time

  1. On the device you will test on, open the invitation email and tap Get Started.
  2. Sign in with the invited Google account and tap Accept invitation.
  3. Tap Download App Tester and install it. If Android asks to allow installs from this source, allow it (see the first snag below).
  4. Open App Tester, find RiskMandate, tap the latest build and tap Install. If Play Protect asks to scan the app, allow it.
  5. Open RiskMandate. The bottom of the home screen shows “Build 0.1.” and a number. That is the number to quote when you report a problem.

Every later build

Firebase emails you and App Tester shows the new build. Tap Install again. A build signed with the same upload key installs over the old one as an update, and the app keeps no data, so nothing is lost. Builds stay available for 150 days.

Two snags we hit on a real tablet

1. Chrome shows the desktop site

Chrome on Android tablets asks for desktop sites by default, so Firebase’s invitation page says “open the invitation on your mobile device” even though you are on one. Turn off Chrome’s Desktop site (Settings, Site settings, Desktop site) or untick it for that tab, then reload.

2. Install unknown apps

The first APK from any app (Chrome, Files, App Tester) triggers “install unknown apps”. Allow it once per source (Settings, Apps, Special app access, Install unknown apps). Allow App Tester, so that updates are one tap. Menu names vary by maker and Android version.

If you have a Google Play build

A Firebase build is signed with the project’s upload key; a build from Google Play is signed by Google. Android refuses to install one over the other, so uninstall first. There is no Play build today, so this only matters later.

If something goes wrong

ProblemTry
No emailLook in spam; ask for the invitation to be resent; check the invited address.
App Tester shows no appsYou are signed in with a different Google account from the invited one.
“App not installed”Uninstall any older copy that was signed with a different key, then retry.
Install blockedAllow installs from this source. A device managed by an organisation may block it.
Nothing happens on “Open riskmandate.ai”No browser is installed or it is disabled; the app then shows a message.

When you report: the build number, device model, Android version, what you did and what you saw. Never send a password, a key or a screenshot of an account page.
