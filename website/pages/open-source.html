Apache 2.0, and what is inside

The code is under the Apache License 2.0 (LICENSE). Anyone may build it. What is meant to be sold, eventually, is the signed, supported build, not the code.

Names and icons are a separate matter: Apache 2.0 gives no trademark rights, and the project’s names and icons are not licensed by it. The copyright holder and a NOTICE file are still to be decided by Dinis Cruz.

No secret belongs in the repository or its history. A scan of every commit on every branch runs before each push (scripts/secret-scan.sh).
